📦 Stock Ledger — Inventory Management System

Stock Ledger is a user-friendly inventory management web application designed to help businesses manage products, track stock movements, monitor inventory levels, and maintain accurate stock records.

🔗 Live Demo: View Stock Ledger

✨ Features
📊 Dashboard Overview — View inventory statistics and stock information.
📦 Inventory Management — Add, update, search, and manage inventory items.
📥 Stock In — Record incoming stock and update inventory quantities.
📤 Stock Out — Track outgoing stock and maintain accurate records.
📜 Transaction History — Review stock movements and inventory activities.
⚠️ Low Stock Alerts — Identify products that need restocking.
📈 Inventory Reports — Generate and export inventory data in CSV format.
💾 Data Backup & Restore — Export and import inventory data using JSON files.
🔍 Search & Filter — Find inventory items quickly and easily.
🎯 Project Objectives

The main objective of Stock Ledger is to simplify inventory management by providing an organized and efficient way to track stock levels, record transactions, reduce manual errors, and maintain inventory records.

🚀 Getting Started

Follow these steps to run the project locally.

1. Clone the Repository
git clone https://github.com/shahrozkhan-tech/Stock-Ledger.git

2. Open the Project Folder
cd Stock-Ledger

3. Run the Application

Open the index.html file in your web browser.

No additional installation is required if the project uses standard HTML, CSS, and JavaScript without external build tools.
